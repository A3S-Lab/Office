## 多人实时协作

浏览器端使用 Yjs，原生智能体使用 Yrs。房间、身份、权限、Provider、离线队列和持久化
由宿主负责，编辑器只通过类型化协议交换内容与 presence 状态。

- [协作协议与状态边界](./components/collaboration.html)
