## 编辑器组件

| 文件类型 | 组件 | 核心实现 |
| --- | --- | --- |
| 文档 | `DocumentEditor` | TipTap / ProseMirror 与 A3S Office 排版内核 |
| Markdown | `MarkdownEditor` | TipTap 可视化编辑与受控 Markdown 源码 |
| 表格 | `SpreadsheetEditor` | 表格交互与 A3S Office 计算内核 |
| 演示文稿 | `PresentationEditor` | 场景图与按需加载的 TipTap 文本编辑 |
| PDF | `PdfViewer` | PDFium WebAssembly 渲染与批注控制器 |

npm 包名是 `@a3s-lab/office`。它提供类型化核心模型、React 组件、Vue
绑定、Web Component 和统一样式。

## 多人实时协作

| 能力 | Document | Markdown | Spreadsheet | Presentation | PDF |
| --- | --- | --- | --- | --- | --- |
| 两台浏览器实时编辑 | ✓ | ✓ | ✓ | ✓ | 覆盖层与审核记录 |
| 在线成员与远端位置 | 文本选区 | 文本选区 | 单元格区域 | 场景对象 | 页面或批注 |
| CLI、MCP 与 A3S Code | ✓ | ✓ | ✓ | ✓ | ✓ |

协作层使用 Yjs/Yrs 标准更新，但不绑定某个后端。宿主继续控制房间、认证、权限、
网络 Provider、离线队列和持久化；编辑器负责格式绑定、参与者列表、远端位置和
本地撤销。完整接入流程、重连语义与限制请查看[多人实时协作](./components/collaboration.mdx)。
