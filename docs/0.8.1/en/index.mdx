## Real-time collaboration

Browsers use Yjs and native agents use Yrs. The host owns rooms, identity,
authorization, providers, offline buffering, and persistence; editors exchange
content and presence through the typed collaboration protocol.

- All five editors share one typed collaboration boundary
- Document comment mode supports attributed threads, replies, resolve/reopen, and own-record deletion
- Document suggestion mode supports attributed insert/delete/replace proposals and immutable editor decisions
- Browser Yjs and native Yrs exchange standard incremental updates
- The A3S Boot example authorizes review semantics before persistence and broadcast
