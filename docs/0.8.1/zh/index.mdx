## 多人实时协作

浏览器端使用 Yjs，原生智能体使用 Yrs。宿主负责房间、身份、权限、Provider、离线队列和持久化；
编辑器通过类型化协作协议交换内容与 presence 状态。

- 五种编辑器使用同一套类型化协作边界
- Document 评论模式支持实名线程、回复、解决/重开和本人记录删除
- Document 建议模式支持署名插入/删除/替换提案与不可变编辑决定
- 浏览器 Yjs 与原生 Yrs 交换标准增量更新
- A3S Boot 示例在持久化和广播前执行审核语义授权
