## Editor components

| File type | Public component | Content model and implementation |
| --- | --- | --- |
| Document | [`DocumentEditor`](./components/document.html) | `DocumentContent`; TipTap / ProseMirror and the A3S Office layout kernel |
| Markdown | [`MarkdownEditor`](./components/markdown.html) | `MarkdownContent`; visual editing with a controlled source |
| Spreadsheet | [`SpreadsheetEditor`](./components/spreadsheet.html) | `SpreadsheetContent`; sparse workbook and calculation kernel |
| Presentation | [`PresentationEditor`](./components/presentation.html) | `PresentationContent`; scene graph with on-demand text editing |
| PDF | [`PdfViewer`](./components/pdf.html) | `Blob` input/output; PDFium WebAssembly and annotation controllers |

All framework bindings share the controlled-component contract. The host owns
content, persistence, permissions, and lifecycle; editors report state changes
through typed properties and events.

## Real-time collaboration

The collaboration protocol covers all five editors and all three framework
bindings. Browsers use Yjs and native agents use Yrs. The host owns rooms,
identity, authorization, providers, offline buffering, and persistence.

## What's new on `main` (0.64.0)

- The WPS-informed evidence matrix now exposes 33 A3S Test ACL contracts and
  24 visual contracts. Spreadsheet covers AutoSum, Paste Special, conditional
  formatting, date/time, cell styles, rich text, table totals, and keyboard
  visibility/color paths; Presentation and PDF add IME/slideshow/large-window
  evidence.

- Sixteen Spreadsheet visual tests passed at both desktop and compact layouts,
  and a live A3S Test 1.0.1 Spreadsheet session committed a typed edit,
  restored grid selection, and reported no page errors.

- Windows interactive A3S Test runs now compile a native `.exe` CDP adapter
  under `.a3s-test/office-ops` when `--cdp-port` is provided, preserving typed
  argv boundaries for selectors and action JSON.

- `doctor --json` reports CUA certification only after a compatible A3S Test
  capability probe; stale local binaries remain fail-closed.

- The shared matrix now covers representative Spreadsheet ribbon/font,
  Presentation focus, and PDF keyboard/compact-drawer workflows alongside the
  Writer WPS contracts. `plan all --json` and `check all` expose the same
  typed inventory across all five editors.

- Windows UI operator dispatch keeps agent action JSON, selectors, and paths in
  typed argv; interactive gates reject stale A3S Test 0.x binaries before
  opening a browser.

- Writer's declarative WPS matrix now includes the shortcut, layout-parity, and
  font/grid A3S Test suites with their deterministic DOCX fixtures. `plan writer
  --json`, `check all`, and `gate writer` expose the same bounded UI/UX contract.

- `office-ui-ops plan <surface> --json` now emits a typed workflow manifest
  from the shared five-surface matrix. It includes deterministic fixtures,
  focused ACL checks, A3S Test gates, desktop/compact visual runs, bounded
  agent sessions, and the Writer WPS reference probes.

- The typed Commander `wps-ui-probe` captures isolated WPS Writer `shell`,
  `fields`, or `all` JSON profiles, including the actual WPS build, window
  geometry, Ribbon/status shell, field command bars, and native command IDs.
  The receipt is local UI/UX reference evidence and does not claim browser
  layout or Windows CUA support.

- Writer now has a typed Field settings dialog for bounded WPS-compatible page,
  section, and bookmark page-reference formats, including numeric switches,
  date/time presets, bookmark targets, hyperlinks, and `MERGEFORMAT` retention.
- A3S Test covers the field-settings workflow at desktop and 390px phone widths,
  including responsive ribbon discovery, live preview, F9 focus restoration,
  accessibility, screenshots, and clean diagnostics. The Commander WPS probe
  also has an explicit `numeric|common` profile.

- Writer PAGE, NUMPAGES, SECTION, SECTIONPAGES, and bookmark-backed PAGEREF
  fields now resolve WPS numeric switches (`Arabic`, `ROMAN`/`roman`,
  `ALPHABETIC`/`alphabetic`, and `Ordinal`) while unknown switches remain
  cached and diagnosed.
- The Commander `wps-fields-probe` captures the installed WPS complex-field
  instructions, and the A3S Test fixture verifies live results, accessible
  labels, F9 focus restoration, screenshots, accessibility, and clean browser
  diagnostics.

- Writer now imports the WPS VML connector shape kinds 32, 33, and 37 as
  typed straight, elbow, and curved connectors. The connector ribbon and live
  SVG share the same kind value; DOCX export writes bounded DrawingML custom
  geometry.
- A3S Test covers the WPS connector-kind matrix with screenshot,
  accessibility, console, and page-error evidence. Arbitrary route-point
  editing and unsupported drawing branches remain fail-closed.
