# A3S Office documentation

A3S Office is a modular browser editor library for documents, Markdown,
spreadsheets, presentations, and PDFs, with host-controlled real-time
collaboration and native agent automation. The Playground is the interactive
home; this site is the stable reference for integration and automation.

## Editor surfaces

| Surface | Public component | Primary engine |
| --- | --- | --- |
| Document | `DocumentEditor` | TipTap/ProseMirror plus the A3S Office layout kernel |
| Markdown | `MarkdownEditor` | TipTap visual editing and a controlled Markdown source model |
| Spreadsheet | `SpreadsheetEditor` | Grid interaction plus the A3S Office calculation kernel |
| Presentation | `PresentationEditor` | Scene graph with on-demand TipTap text editing |
| PDF | `PdfViewer` | PDFium WebAssembly rendering and annotation controllers |

The public package is `@a3s-lab/office`. It exposes typed core models, React
components, Vue bindings, custom elements, and one shared stylesheet.

## Real-time collaboration across every surface

| Capability | Document | Markdown | Spreadsheet | Presentation | PDF |
| --- | --- | --- | --- | --- | --- |
| Two-browser live editing | ✓ | ✓ | ✓ | ✓ | Overlays and review records |
| Participants and remote locations | Text selection | Text selection | Cell range | Scene object | Page or annotation |
| CLI, MCP, and A3S Code peers | ✓ | ✓ | ✓ | ✓ | ✓ |

The Yjs/Yrs boundary is backend-neutral. The host retains rooms,
authentication, authorization, the network provider, offline buffering, and
persistence; editors own format bindings, the participant roster, remote
locations, and local undo. See [Real-time collaboration](./components/collaboration.mdx)
for the complete setup, reconnect behavior, and limitations.
