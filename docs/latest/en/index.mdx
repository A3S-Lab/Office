      <h2 id="docs-home-collaboration-title">Collaboration is a complete path</h2>
      <p>Office owns format bindings, participants, remote locations, and local undo. The host keeps ownership of rooms, authentication, authorization, the network provider, offline buffering, and persistence.</p>
      <ul className="docs-home-collaboration__facts">
        <li>All five editors share one typed collaboration boundary</li>
        <li>Document comment mode supports attributed threads, replies, resolve/reopen, and own-record deletion</li>
        <li>Document suggestion mode supports attributed insert/delete/replace proposals and immutable editor decisions</li>
        <li>Character-formatting revisions accept the new marks or restore the exact prior formatting and round-trip as DOCX <code>w:rPrChange</code></li>
        <li>Spreadsheet Tables/ListObjects converge as validated, ordered ID-keyed records instead of serialized worksheets</li>
        <li>Browser Yjs and native Yrs exchange standard incremental updates</li>
        <li>The A3S Boot example authorizes review semantics before persistence and broadcast</li>
      </ul>
