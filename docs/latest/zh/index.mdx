## 编辑器组件

| 文件类型 | 公开组件 | 内容模型与实现 |
| --- | --- | --- |
| 文档 | [`DocumentEditor`](./components/document.html) | `DocumentContent`；TipTap / ProseMirror 与 A3S Office 排版内核 |
| Markdown | [`MarkdownEditor`](./components/markdown.html) | `MarkdownContent`；可视化编辑与受控源码 |
| 表格 | [`SpreadsheetEditor`](./components/spreadsheet.html) | `SpreadsheetContent`；稀疏工作簿与计算内核 |
| 演示文稿 | [`PresentationEditor`](./components/presentation.html) | `PresentationContent`；场景图与按需文本编辑 |
| PDF | [`PdfViewer`](./components/pdf.html) | `Blob` 输入/输出；PDFium WebAssembly 与批注控制器 |

所有框架绑定共享受控组件约定。宿主持有内容、保存状态、文件权限和生命周期，编辑器
通过类型化属性与事件返回状态变化。

## 多人实时协作

协作协议适用于全部五种编辑器和三种框架绑定。浏览器端使用 Yjs，原生智能体使用 Yrs，
宿主负责房间、身份、权限、Provider、离线队列和持久化。

- [协作协议与状态边界](./components/collaboration.html)
- [完整 A3S Boot 后端示例](./components/collaboration-server.html)
